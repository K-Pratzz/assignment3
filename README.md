# Inventory and Data Management System

A backend RESTful API built for store and warehouse inventory management using **Node.js**, **Express.js**, **MongoDB**, and **Mongoose**[cite: 1]. This application supports full CRUD operations, advanced query filtering, sorting, pagination, safe stock adjustments, and aggregation reporting[cite: 1, 5].

---

## 🚀 Tech Stack
* **Node.js** - Runtime environment[cite: 1]
* **Express.js** - Web framework and routing[cite: 1]
* **MongoDB** - NoSQL database[cite: 1]
* **Mongoose** - Object Data Modeling (ODM) library[cite: 1]
